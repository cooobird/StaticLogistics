# StaticLogistics

**[English](README.md)** | **[中文](README_ZH.md)**

StaticLogistics 是面向 NeoForge 1.21.1 的无管线物流模组。它以方块的具体连接面为节点，在可配置距离与维度之间传输物品、流体、能量及联动模组资源，并通过一个统一的链接配置器完成建链、分组、预览和配置。

## 当前架构

```text
所有者
└─ 分组（稳定内部 ID + 可修改显示名称）
   └─ 连接（可单独命名）
      ├─ 端点 A：维度 + 方块坐标 + 连接面
      └─ 端点 B：维度 + 方块坐标 + 连接面
```

- **节点是方块面，不是整个方块。** 同一容器的不同朝向是不同节点，可以分别承担输入或输出职责。
- **连接只描述两个端点之间的拓扑关系。** 实际传输方向由两端当前启用的输入/输出职责决定，因此同一条连接可以单向、双向或暂时停用。
- **分组属于明确的所有者。** 显示名称不是身份；重命名不会破坏链接，同一所有者下重命名为已有名称时会合并分组。
- **输出类型属于输出面。** 输入面显示的接收类型由相连输出端推导，不是另一份可独立修改的类型列表。
- **速度、范围、堆叠和维度能力属于容器。** 同一方块的所有连接面共享一组容器升级。
- **过滤器和传输规则属于面。** 输入、输出过滤器，优先级、存量维持、分发策略、提取策略及输出类型都随具体连接面保存。
- **服务端是最终权威。** 分组身份、所有权、权限、链接、配置和资源返还均由服务端校验与提交。

旧版独立节点配置模式已经移除。链接配置器是节点配置、分组管理和网络预览的唯一入口。

## 核心功能

- 统一链接配置器：同屏管理工具模式、资源类型、网络拓扑、分组、连接、节点配置和玩家物品栏
- 面级链接：精确区分维度、坐标与连接朝向
- 可交互网络预览：平移、缩放、节点拖动、框选、多选、批量拖动、批量配置和连接高亮
- 分组与连接管理：创建、折叠、选择、重命名、合并和带确认的删除
- 世界内预览：按整个分组或单条连接限制渲染范围
- 容器共享升级：速率、范围、堆叠和跨维度能力
- 双侧过滤：输入端和输出端可分别安装基础、标签或 NBT 过滤器
- 可扩展资源类型：内置物品、流体和能量，并按已安装模组动态加入其他类型
- 蓝图：按分组或连接预览、复制和粘贴物流配置
- 权限系统：玩家所有权、FTB Teams 队伍访问和服务端管理命令
- 公共传输适配 API 与传输前/后事件

## 快速上手

1. 合成并手持**链接配置器**。
2. 普通右键打开配置器，创建并选中一个分组。
3. 在顶部选择新连接默认启用的资源类型。可以不选类型建立空闲连接，之后再配置输出端。
4. 选择“选取点为存入端”或“选取点为提取端”，潜行右键一个或多个方块面以记录节点。
5. 切换到相反的选点模式，再潜行右键另一端；记录的节点会与当前节点批量建立连接。
6. 在网络预览中点击节点，在下方配置该面的职责、过滤器、升级和传输规则。

例：将一个箱子发送到三个机器时，先用“存入端”记录三个机器面，再切换为“提取端”并潜行右键箱子面。

### 配置器操作

| 操作            | 结果            |
|---------------|---------------|
| 普通右键          | 打开统一配置器       |
| 潜行 + 右键节点     | 执行当前工具模式      |
| 配置的模式切换键 + 滚轮 | 切换工具模式        |
| 配置的批量选点键 + 右键 | 选取相连的同类方块及可用面 |
| 潜行右键空气        | 清除配置器中暂存的节点   |

### 工具模式

| 模式      | 用途                |
|---------|-------------------|
| 扳手      | 对支持的方块执行扳手/拆卸操作   |
| 选取点为存入端 | 记录资源将进入的端点        |
| 选取点为提取端 | 记录资源将离开的端点        |
| 移除现有链路  | 从当前选中分组中移除该面关联的连接 |

移除连接、删除分组或关闭相关职责时，可返还的过滤器和升级会优先进入操作者背包，背包放不下时才会掉落。

## 配置器界面

配置器由四个职责明确的区域组成：

- **顶部工具栏**：切换工具模式、资源类型页和新建连接的默认类型；选中输出节点后，这里改为编辑该输出面的类型。
- **网络预览**：显示当前分组或连接的真实面级拓扑。
- **分组与连接**：选择预览范围，展开连接，创建分组，重命名或删除条目。
- **节点配置**：编辑网络预览中选中的一个或多个节点。

资源类型与工具模式是两份互不覆盖的状态；分组选择与单条连接选择也分别持久化。

### 网络预览

- 单击节点选择并配置；单击连接只聚焦该连接。
- 按住可配置的复选键点击节点，可加入或移除多选。
- 按住复选键拖动空白区域，可框选多个节点。
- 拖动已选节点会整体移动当前选择；拖动普通空白区域会平移画布。
- 滚轮以鼠标位置为中心等比例缩放。
- 右键空白区域清空当前选择。
- 自定义节点位置保存在客户端本地，并按稳定分组身份恢复；重新打开界面时视图会重新对准当前拓扑。
- 正常连接使用常规颜色，超出有效范围或当前不可传输时使用警告颜色；悬停连接可查看原因。
- 相同方块坐标但不同连接面的节点仍会分别显示。

批量配置会复制当前节点的资源类型、过滤器、容器升级和对应侧设置到全部选中节点，并由服务端统一校验与结算物品。

### 分组与连接

- 分组和连接都可以选择、重命名和删除。
- 删除操作会先显示确认窗口。
- 同一所有者下，把分组重命名为已有名称会合并两者及其连接。
- 选中整个分组时，网络预览和世界渲染显示该组全部连接；选中单条连接时只显示该连接。
- 删除连接会同步清理两端的反向引用；没有任何连接的端点不会保留无效输入/输出职责。

## 节点配置模型

### 输入侧

- 启用或关闭输入职责
- 输入过滤器
- 优先级
- 存量维持
- 接收类型只读显示，由相连输出端推导

### 输出侧

- 启用或关闭输出职责
- 输出过滤器
- 输出资源类型
- 容器共享升级
- 目标分发策略
- 物品槽位提取策略

关闭单侧职责只会停止对应方向，不会删除拓扑连接；重新启用后可继续使用原连接。

## 资源类型

内置类型：

- 物品
- 流体
- 能量

可选联动会在对应模组存在时注册额外类型：

| 模组          | 资源类型   |
|-------------|--------|
| Mekanism    | 化学品、热量 |
| Ars Nouveau | 魔源     |
| Botania     | 魔力     |

类型列表来自运行时注册表并支持分页，第三方模组可通过公开的 `ResourceAdapter<C, V>` SPI
加入稳定类型。详细接口见 [集成文档](docs/INTEGRATION.md)。

若输出面没有选中任何类型，连接会保留但不会从该面发起传输。Jade 显示的“传输类型”来自输出面的实际选择，“接收类型”来自相连输出端，不按容器能力列表猜测。

## 升级

速度、范围、堆叠升级具有五个等级：铁、金、钻石、下界合金和下界之星。维度升级为独立单级插件。

| 槽位能力    | 效果                              |
|---------|---------------------------------|
| 速率      | 缩短容器的传输激活间隔                     |
| 范围 / 维度 | 范围升级扩大最大连接距离；维度升级允许跨维度并解除普通距离限制 |
| 堆叠      | 提高每次激活可传输的资源量                   |

升级属于容器而不是某一条连接。只要同一容器仍有其他有效连接，共享升级就会保留；最后一条相关连接被移除或容器被拆除时才统一返还。

等级倍率可在 `config/staticlogistics.toml` 中修改。配置重新载入后，既有连接会直接使用新数值，无需重新建链。

## 过滤器

过滤器是独立插件，不属于速度、范围或堆叠升级等级。

| 过滤器     | 匹配内容                      |
|---------|---------------------------|
| 基础过滤器   | 指定物品或流体身份                 |
| 标签过滤器   | 物品标签与流体标签，并支持明确排除标签       |
| NBT 过滤器 | 指定物品及其数据组件，支持部分/完全匹配和忽略耐久 |

三种过滤器均支持白名单与黑名单。输入面与输出面各有独立过滤器槽位。基础和标签过滤器只保存匹配所需的身份数据；NBT
过滤器保留用于组件匹配的模板数据。

## 传输规则

### 目标分发

- 顺序优先
- 轮询
- 最近
- 最远
- 随机

### 物品提取

- 顺序提取
- 槽位轮询

物品提取会遍历容器中的可用槽位并跳过被过滤或无法接收的候选，而不是永久停留在前几格。大型网络由公平游标、失败冷却、候选批次和每
tick 软时间预算共同调度，避免单个网络长期占满服务器 tick。

传输只访问已加载且仍具备对应能力的端点，不会为了远程连接强制加载区块。方块被破坏或正确拆除后，相关连接会从两端清理。

## 蓝图

物流蓝图用于复制已有物流配置，而不是替代配置器：

1. 在蓝图分组界面展开分组。
2. 选择整个分组或其中一条连接，世界中只预览对应范围。
3. 选择区域的两个角点进行捕获。
4. 在目标位置预览，移动或旋转后确认粘贴。
5. 需要时使用可配置的撤销键恢复上一次粘贴。

粘贴会校验权限、目标区域和所需升级；蓝图提示会显示捕获范围与升级需求。

## 所有权与权限

- 首次写入节点时记录所有者，所有后续修改均按所有者校验。
- 分组内部使用稳定身份，显示名称仅用于玩家操作。
- 安装 FTB Teams 后，队伍成员访问由队伍权限策略统一判断。
- 服务端管理命令需要权限等级 2。

## 命令

| 命令                                    | 说明            |
|---------------------------------------|---------------|
| `/sl info [pos]`                      | 查看容器及六个面的物流配置 |
| `/sl list`                            | 查看分组列表第一页     |
| `/sl list page <page>`                | 分页查看分组        |
| `/sl list group <group> [page]`       | 分页查看指定分组      |
| `/sl stats`                           | 查看传输统计        |
| `/sl stats recent`                    | 查看最近传输        |
| `/sl stats top`                       | 查看主要发送/接收节点   |
| `/sl stats reset`                     | 重置统计          |
| `/sl transfer <from> <to>`            | 转移玩家的全部物流所有权  |
| `/sl transfer <from> group <id> <to>` | 转移指定分组        |
| `/sl rename <owner> <old> <new>`      | 重命名或合并分组      |
| `/sl cleanup <owner>`                 | 清理指定玩家的物流数据   |

## 服务端配置

`config/staticlogistics.toml` 的当前结构：

```toml
[general]
gameplay_mode = "ADVANCED"
default_radius = 16
default_tick_interval = 20
auto_clean_stored_nodes = true
item_stack_size = 64
fluid_stack_size = 250
energy_stack_size = 1024
mek_chemical_stack_size = 250
mek_heat_stack_size = 1000
ars_source_stack_size = 100
botania_mana_stack_size = 1000

[performance]
provider_size = 1000
max_bulk_entries = 100
ticker_batch_size = 50
ticker_time_budget_us = 1500
clean_interval = 200
default_cooldown = 10
batch_clean_threshold = 500
batch_clean_size = 200
context_pool_size = 100

[upgrades]
iron_multiplier = 2
gold_multiplier = 4
diamond_multiplier = 8
netherite_multiplier = 16
nether_star_multiplier = 64
```

- `gameplay_mode` 可设为 `SIMPLE`（无需升级，传输间隔固定为 1 Tick，各资源单次传输量固定为 `999999999`，并无视距离与维度限制）或
  `ADVANCED`（默认，使用配置值和升级系统）。切换后会热更新已有网络，且不会删除已安装的升级。
- `default_*_stack_size` 决定各资源类型的基础单次传输量。
- `ticker_batch_size` 是每 tick 轮询的候选基数，不是节点总数限制。
- `ticker_time_budget_us` 是所有维度共享的软时间预算；到达预算后剩余工作顺延到后续 tick。
- `provider_size` 只用于预估索引容量。
- 升级倍率和基础传输量均支持配置热更新，已有网络会自动采用新值。

## 存档兼容

- 资源类型使用稳定 ID 与稳定位序，现有链接不会因注册表顺序变化而断开。
- 旧版类型掩码、分组名称、链接和面存储数据会在加载时迁移。
- 分组重命名只改变显示名称，不改变稳定内部身份。
- 网络预览布局保存在客户端本地，不参与服务端传输拓扑。

## 开发者扩展

- 公共资源适配 SPI：`StaticLogisticsApi.resourceAdapters()`
- 可取消的 `PreTransferEvent`
- 传输完成后的 `PostTransferEvent`
- 可注册的分发策略

第三方只应依赖公开 API 包；内部的 `LogisticsResource`
和节点实现不属于稳定集成契约。参见 [docs/INTEGRATION.md](docs/INTEGRATION.md)。
