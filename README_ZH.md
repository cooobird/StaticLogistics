# StaticLogistics

**[English](README.md)** | **[中文](README_ZH.md)**

StaticLogistics 是面向 Forge 1.20.1 的无管线物流模组。它以方块的具体连接面为节点，在可配置距离与维度之间传输物品、流体、能量及联动模组资源，并通过一个统一的链接配置器完成建链、分组、预览和配置。

## 当前架构

```text
所有者
└─ 分组（稳定内部 ID + 可修改显示名称）
   └─ 连接（可单独命名）
      ├─ 端点 A：维度 + 方块坐标 + 连接面
      └─ 端点 B：维度 + 方块坐标 + 连接面
```

- 节点代表具体方块面，同一容器的不同朝向是不同节点。
- 连接保存两个端点之间的拓扑关系；实际方向由两端启用的输入/输出职责决定，可单向、双向或暂时停用。
- 分组属于明确所有者，并使用不随重命名变化的内部身份；同一所有者下重命名为已有名称会合并分组。
- 输出类型保存在输出面；输入面显示的接收类型由相连输出端推导。
- 速度、范围、堆叠和维度升级属于容器，同一方块的全部连接面共享。
- 输入/输出过滤器、优先级、存量维持、分发、提取和类型选择属于具体连接面。
- 服务端负责权限、链接、配置、资源结算与持久化，客户端只提交操作意图。

旧版独立节点配置模式已经移除。链接配置器是节点设置、分组管理和网络预览的唯一入口。

## 核心功能

- 统一链接配置器：管理工具模式、资源类型、拓扑、分组、连接、节点配置和玩家物品栏
- 精确到连接面的跨距离、跨维度物流连接
- 可平移、缩放、拖动、框选、多选、批量拖动和批量配置的网络预览
- 可创建、折叠、重命名、合并和安全删除的分组与连接
- 按整个分组或单条连接限制的世界预览
- 容器共享的速率、范围、堆叠与维度升级
- 输入端和输出端独立过滤器
- 运行时可扩展的资源类型注册表
- 物流蓝图捕获、预览、移动、旋转、粘贴和撤销
- 玩家所有权、FTB Teams 权限和服务端管理命令
- 公共资源适配 API 与传输事件

## 快速上手

1. 合成并手持**链接配置器**。
2. 普通右键打开配置器，创建并选中一个分组。
3. 在顶部选择新连接默认启用的资源类型；不选类型也可先建立连接。
4. 选择“选取点为存入端”或“选取点为提取端”，潜行右键一个或多个方块面以记录节点。
5. 切换到相反模式，再潜行右键另一端，记录节点会与当前节点批量建链。
6. 在网络预览中选择节点，在下方编辑输入/输出职责、过滤器、升级和传输规则。

例如，一个箱子向三台机器供货时，先用“存入端”记录三个机器面，再切换为“提取端”并潜行右键箱子面。

### 基本操作

| 操作            | 结果            |
|---------------|---------------|
| 普通右键          | 打开统一配置器       |
| 潜行 + 右键节点     | 执行当前工具模式      |
| 配置的模式切换键 + 滚轮 | 切换工具模式        |
| 配置的批量选点键 + 右键 | 选取相连的同类方块及可用面 |
| 潜行右键空气        | 清除暂存节点        |

| 工具模式    | 用途              |
|---------|-----------------|
| 扳手      | 对支持的方块执行扳手或拆卸操作 |
| 选取点为存入端 | 记录资源接收端         |
| 选取点为提取端 | 记录资源提供端         |
| 移除现有链路  | 从当前分组移除该面关联的链接  |

移除连接、删除分组或关闭相关职责时，可返还的过滤器与升级优先进入操作者背包，背包放不下时才会掉落。

## 配置器与网络预览

配置器分为顶部工具栏、网络预览、分组与连接、节点配置四个区域。工具模式、资源类型、分组选择和单条连接选择是互相独立的状态，不会彼此覆盖。

- 单击节点进行配置，单击连线聚焦单条连接。
- 按住可配置的复选键点击节点可增减多选；按住该键拖动空白区域可框选。
- 拖动任一已选节点可整体移动所选节点；拖动普通空白区域可平移画布。
- 滚轮以鼠标位置为中心等比例缩放，右键空白区域清空选择。
- 节点位置保存在客户端本地，并按稳定分组身份恢复；重新打开界面时视图会对准当前拓扑。
- 相同方块坐标但不同连接面的节点分别显示。
- 正常连接使用常规颜色，超距或当前阻塞的连接使用警告颜色并在悬停时说明原因。
- 批量配置会把当前节点的类型、过滤器、容器升级和对应侧设置统一应用到所选节点。

### 分组与连接

- 分组和连接均可选择、重命名和删除，删除前会二次确认。
- 同一所有者下，把分组重命名为已有名称会合并两组及其连接。
- 选择分组会预览全部连接；选择单条连接只预览该连接。
- 删除连接会同步清理两个端点；无连接的面不会保留无效输入/输出职责。

## 节点配置

### 输入侧

- 输入职责开关
- 输入过滤器
- 优先级
- 存量维持
- 由相连输出端推导的只读接收类型

### 输出侧

- 输出职责开关
- 输出过滤器
- 输出资源类型
- 容器共享升级
- 目标分发策略
- 物品槽位提取策略

关闭某一职责只停止对应方向，不会删除拓扑连接。

## 资源类型

内置物品、流体和能量。可选联动按已安装模组动态注册：

| 模组           | 资源类型           |
|--------------|----------------|
| Mekanism     | 气体、灌注、颜料、浆液、热量 |
| Ars Nouveau  | 魔源             |
| Botania      | 魔力             |
| GregTech CEu | EU             |

输出面没有选中类型时，连接保留但不会从该面传输。Jade 的“传输类型”来自输出面的实际选择，“接收类型”来自相连输出端，而不是容器能力猜测。

第三方可通过公开的 `ResourceAdapter<C, V>` SPI 注册稳定资源类型，详见 [集成文档](docs/INTEGRATION.md)。

## 升级

速率、范围和堆叠升级拥有铁、金、钻石、下界合金和下界之星五个等级；维度升级为独立单级插件。

| 容器能力    | 效果                        |
|---------|---------------------------|
| 速率      | 缩短传输激活间隔                  |
| 范围 / 维度 | 扩大连接距离；维度升级允许跨维度并解除普通距离限制 |
| 堆叠      | 提高每次激活可传输的资源量             |

升级属于容器。容器仍有其他连接时共享升级会保留，最后一条相关连接被移除或容器被拆除后才统一返还。配置热重载后，既有网络直接使用新的基础量和升级倍率。

## 过滤器

| 过滤器     | 匹配内容                |
|---------|---------------------|
| 基础过滤器   | 指定物品或流体身份           |
| 标签过滤器   | 物品/流体标签及明确排除标签      |
| NBT 过滤器 | 物品数据，支持部分/完全匹配和忽略耐久 |

过滤器是独立插件，不属于性能升级等级。三种过滤器均支持白名单与黑名单，输入端和输出端各自保存过滤规则。

## 传输策略与调度

目标分发支持顺序、轮询、最近、最远和随机；物品提取支持顺序与槽位轮询。

物品提取会遍历可用槽位并跳过被过滤或目标无法接收的候选。大型网络通过公平游标、失败冷却、候选批次和每 tick
软时间预算调度，避免单个网络长期占满服务器。传输只访问已加载且仍具有对应能力的端点，不会强制加载远程区块。

方块被破坏或正确拆除时，相关连接会从两端清理。

## 蓝图

物流蓝图复制已有物流配置：

1. 在蓝图分组界面展开分组并选择整个分组或单条连接。
2. 通过世界预览确认要捕获的物流范围。
3. 选择区域的两个角点。
4. 在目标位置移动或旋转预览，然后确认粘贴。
5. 使用可配置的撤销键恢复上一次粘贴。

粘贴过程会校验权限、区域和升级需求。

## 权限

- 首次写入节点时记录所有者。
- 分组内部身份不会因重命名而变化。
- 安装 FTB Teams 后，队伍成员访问由统一队伍策略判断。
- 服务端管理命令需要权限等级 2。

## 命令

| 命令                                    | 说明          |
|---------------------------------------|-------------|
| `/sl info [pos]`                      | 查看容器及六面配置   |
| `/sl list`                            | 查看分组列表第一页   |
| `/sl list page <page>`                | 分页查看分组      |
| `/sl list group <group> [page]`       | 分页查看指定分组    |
| `/sl stats`                           | 查看传输统计      |
| `/sl stats recent`                    | 查看最近传输      |
| `/sl stats top`                       | 查看主要发送/接收节点 |
| `/sl stats reset`                     | 重置统计        |
| `/sl transfer <from> <to>`            | 转移全部物流所有权   |
| `/sl transfer <from> group <id> <to>` | 转移指定分组      |
| `/sl rename <owner> <old> <new>`      | 重命名或合并分组    |
| `/sl cleanup <owner>`                 | 清理指定玩家的物流数据 |

## 服务端配置

```toml
[general]
gameplay_mode = "ADVANCED"
default_radius = 16
default_tick_interval = 20
auto_clean_stored_nodes = true
item_stack_size = 8
fluid_stack_size = 250
energy_stack_size = 1024
mek_gas_stack_size = 250
mek_infusion_stack_size = 250
mek_pigment_stack_size = 250
mek_slurry_stack_size = 250
mek_heat_stack_size = 1000
ars_source_stack_size = 100
botania_mana_stack_size = 1000
gtceu_stack_size = 1024

[performance]
provider_size = 1000
max_bulk_entries = 100
ticker_batch_size = 50
ticker_time_budget_us = 1500
clean_interval = 200
default_cooldown = 10
batch_clean_threshold = 500
batch_clean_size = 200
context_pool_size = 100

[upgrades]
iron_multiplier = 2
gold_multiplier = 4
diamond_multiplier = 8
netherite_multiplier = 16
nether_star_multiplier = 64
```

`gameplay_mode` 可设为 `SIMPLE`（传输间隔固定为 1 Tick，各资源单次传输量固定为 `999999999`，无视距离与维度限制，
并隐藏升级槽位）或 `ADVANCED`（默认，使用配置值和已安装升级）。

`ticker_batch_size` 是候选轮询基数而非节点总数限制；`ticker_time_budget_us` 是全部维度共享的软预算；`provider_size`
只用于预估索引容量。

## 存档兼容

Forge 1.20.1 资源 ID 与稳定位序保持不变：

`item=0`、`fluid=1`、`energy=2`、`mek_gas=3`、`mek_infusion=4`、`mek_pigment=5`、`mek_slurry=6`、`mek_heat=7`、`ars_source=8`、
`botania_mana=9`、`gtceu_energy=10`。

旧版类型掩码、分组名称、链接和面存储数据会在加载时迁移。网络预览布局保存在客户端本地，不会修改服务端传输拓扑。
